Рабочая папка - файлы проекта, с которыми работает пользователь



Индекс - область работы, которая еще не выгружена в коммит, но уже содержит изменения



Коммит - сохранение прогресса на данном этапе. В любой момент можно откатиться к определённому коммиту, если это понадобится. Что-то типа ячейки сохранения в играх.



GitHub в отличие от Git является не рабочей зоной, а облачным хранилищем, куда выкладывается код. Git нужен для работы локально на компе, а GitHub - чтобы продолжить работу на другом устройстве лично или для продолжения работы другим человеком.



git status показывает состояние рабочей папки и индекса



git diff показывает изменения с файлом, которые еще не добавлены через add. git diff --staged показывает изменения, добавленные через add, но еще не коммиченные.



Ветки:



ветка - ответвление в коде, чтобы не затрагивая главный код можно было работать над новыми функциями, потом скрещивая их с главным кодом - это называется слиянием. ч	при коммите все изменения происходят в самой ветке, не затрагивая условный main.
