git diff показывает изменения до add и коммита, git show показывает изменения в выбранном коммите (или последнем, если коммит не указан) а git log показывает информацию о коммитах.



log -S"" ищет коммиты, в которых была изменена строка в кавычках



blame показал строки из файла с датами их добавления с точностью до секунд.



git restore возвращает файл в состояние последнего коммита, source позволяет указать конкретный коммит, к которому нужно перейти. правки сотрутся.



git revert создаёт новый коммит, git reset --hard полностью стирает коммиты и изменения. после revert можно будет вернуться к "стёртому" коммиту, если понадобится, после reset --hard такого не выйдет.



ветка - не статичный указатель, автоматически перемещается вперед за каждым коммитом. ветки нужны для экспериментов без риска для основной работы. тег - это статичный указатель для указания важных этапов в истории проекта.
